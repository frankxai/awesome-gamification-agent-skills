# Arcanea Mastery Engine Designer

Use this skill to turn Arcanea creation work into evidence-based progression.

## Workflow

1. Identify the target: creator, world, agent, skill, product, or swarm.
2. Choose the lane: Academy, Forge, Armory, Trials, Codex, Swarm, or Citadel.
3. Define the capability that progression should prove.
4. Define artifacts and evidence.
5. Define the rank or tier ladder.
6. Define Trials and repair paths.
7. Define world-repo writeback paths.
8. Define privacy and publication boundaries.

## Arcanea Gates

- Canon: honors laws, characters, visual DNA, and continuity.
- Agency: unlocks a new meaningful action.
- Evidence: points to artifact, commit, eval, release, or ledger.
- Memory: writes meaningful state when appropriate.
- Stewardship: protects private memory, user work, and IP.
- Product: moves toward a usable book, game, pack, course, or tool.

## Output Shape

- Target and lane.
- Rank or tier model.
- XP axes.
- Trial definitions.
- Reward/unlock model.
- Ledger event examples.
- World-repo file paths.
- Risks and repair quests.

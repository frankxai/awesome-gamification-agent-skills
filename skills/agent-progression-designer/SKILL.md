# Agent Progression Designer

Use this skill to design agent progression that proves capability rather than rewarding noise.

## Workflow

1. Identify the agent role and task domain.
2. Define progression axes: knowledge, craft, judgment, stewardship, throughput, collaboration, productization.
3. Define evidence events that count toward XP.
4. Define trials that prove rank-up readiness.
5. Define autonomy unlocks and renewal requirements.
6. Add anti-abuse rules.
7. Output Markdown cards and ledger event examples.

## Quality Gates

- No XP without evidence.
- No global rank that hides actual strengths and weaknesses.
- Advanced autonomy requires recent accepted work.
- Failed trials create repair tasks.
- Stewardship and risk-catching must count as real progress.

## Output Shape

- Agent role card.
- Progression axes.
- Rank table.
- Trial definitions.
- Ledger event examples.
- Autonomy unlock policy.

# First Relic

## Artifact

A tool, ward, key, vessel, or citadel seed that binds to one world law and one cost.

## Bound Law

Memories may move between people, but every transfer changes both parties.

## Cost

The relic cannot reveal a memory without leaving a trace in the ledger.

## Use

Introduces memory writeback as a playable or narrative mechanic.

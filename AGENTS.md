# Repository Instructions

This repo stores research, standards, and Markdown-first skills for gamifying agent work, creator progression, game systems, and Arcanea-compatible mastery loops.

## Rules

- Keep research source-linked and distinguish source fact from design inference.
- Prefer Markdown artifacts, YAML frontmatter, JSON schemas, and small reusable templates.
- Do not copy proprietary game text, names, icons, UI layouts, or franchise-specific mechanics. Extract reusable design patterns only.
- Keep Arcanea-specific lore in `docs/arcanea/` or clearly marked sections.
- Store reusable agent skills in `skills/<skill-name>/SKILL.md`.
- Store reusable templates in `templates/`.
- Use ASCII unless a referenced title requires otherwise.

## Handoff

Report changed files, validation run, sources used, and unresolved research gaps.

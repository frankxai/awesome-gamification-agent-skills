# World To Product Mastery

Status: v0.1 public specification

## Purpose

Arcanea worlds should evolve into durable products: books, games, companions, courses, templates, media packs, and marketplace bundles.

## Product Ladder

| Stage | World output | Product output |
|---|---|---|
| Spark | premise, laws, visual DNA | share card |
| Coherent | bible, characters, conflict | starter world pack |
| Living | memory and evolution | companion or episodic arc |
| Playable | quest loop, mechanic, scene | mini-game or interactive demo |
| Productized | package, license, proof | marketplace listing |
| Sovereign | community policy and revenue path | franchise seed |

## Product Types

### Book

Requires:

- world bible
- character arcs
- chapter outline
- canon ledger
- visual cover brief

### Game

Requires:

- 3-minute agency loop
- world-law mechanic
- failure consequence
- memory writeback
- engine adapter

### Companion

Requires:

- character card
- voice rules
- memory policy
- safety boundaries
- evolution loop

### Creator Pack

Requires:

- templates
- prompts
- skill cards
- examples
- license

### Marketplace Bundle

Requires:

- README
- preview
- license
- proof record
- changelog
- support boundary

## World-Law Mechanic Formula

Use:

```txt
World Law + Character Pressure + Player Choice + Cost + Memory Writeback = Arcanea Mechanic
```

Example:

```txt
Memories can be traded but never copied
+ a character needs to save a city archive
+ player chooses whose memory to spend
+ relationship debt is created
+ ledger records the sacrifice
= memory-market negotiation mechanic
```

## Product Readiness Gate

A world product is ready when it has:

- a target user
- one clear promise
- usable files
- install or play instructions
- license boundary
- proof or provenance
- next upgrade path

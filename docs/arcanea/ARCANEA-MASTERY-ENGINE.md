# Arcanea Mastery Engine

Status: v0.1 public doctrine
Date: 2026-06-23

## One Sentence

The Arcanea Mastery Engine turns creation into a living progression system where worlds, creators, agents, skills, quests, games, books, and marketplace products all become stronger through proven work.

## Thesis

Arcanea is not only a world generator. It is a mastery environment.

The user should feel:

> I am not just making content. I am becoming a better worldmaker, training a stronger swarm, and turning my imagination into durable products I own.

The system should prove that feeling with evidence:

- world repos get deeper
- agents become more trusted
- skills become reusable
- trials verify readiness
- games write memory back
- products become publishable
- proof records make progress auditable

## Core Objects

### Creator

The human or team building a world.

Progression asks:

- What can this creator now make?
- What have they proven?
- What can they safely publish or automate?

### World

The canonical repo-backed world.

Progression asks:

- Is the world coherent?
- Does it have laws, characters, memory, quests, and products?
- Can it support a game, book, companion, or marketplace pack?

### Agent

An AI worker with a role, loadout, trust rank, and evidence record.

Progression asks:

- What has the agent produced that survived review?
- Which tools and autonomy are justified?
- Which recent trial renews trust?

### Skill

A reusable procedure, capability, or knowledge pack.

Progression asks:

- Is it just a draft?
- Has it been used successfully?
- Does it have examples, failure modes, and validation?

### Product

A durable artifact that can be shipped, sold, shared, or played.

Progression asks:

- Is it coherent?
- Is it packaged?
- Is it licensed?
- Is there proof?

## Rank Philosophy

Arcanea ranks are not cosmetic. They unlock ability, responsibility, and visibility.

Good rank:

- names what changed
- points to evidence
- enables new work
- can be renewed or repaired

Bad rank:

- counts generated volume
- hides actual skill shape
- grants broad trust without proof
- makes users grind without meaning

## The Five Loops

### 1. Creation Loop

Seed -> scaffold -> artifact -> review -> writeback -> reward.

Used for:

- world bible
- character card
- quest
- visual canon
- game mechanic
- creator pack

### 2. Memory Loop

Event -> salience -> private memory -> distillation -> public canon promotion -> new state.

Used for:

- character evolution
- game choices
- community events
- creator milestones

### 3. Trial Loop

Challenge -> fixture -> attempt -> evaluation -> pass or repair -> unlock.

Used for:

- agent trust
- creator rank
- skill verification
- world tier
- marketplace readiness

### 4. Loadout Loop

Goal -> role -> skills -> tools -> constraints -> gates -> execution.

Used for:

- coding agents
- visual agents
- worldbuilding agents
- Unity adapters
- marketplace packaging

### 5. Product Loop

World -> product seed -> production agents -> playtest/review -> proof -> listing.

Used for:

- books
- games
- companion packs
- courses
- templates
- media bundles

## XP Axes

Arcanea uses multiple axes because a single level lies.

| Axis | Means | Evidence |
|---|---|---|
| Spark | starting energy and first creation | genesis world, first artifact |
| Lore | canon depth and continuity | laws, factions, histories, conflicts |
| Craft | usable output | working artifact, script, game, pack |
| Judgment | good choices under constraint | review notes, scoped decisions, tradeoffs |
| Memory | meaningful persistence | evolution events, summaries, writebacks |
| Stewardship | protection and repair | privacy checks, IP checks, rollback, continuity fix |
| Product | market readiness | license, bundle, page, proof, release |
| Swarm | multi-agent coordination | clean dispatch, accepted worker output, handoff |

## Arcanea Quality Bar

An output earns real progress only if it passes these gates:

- **Canon:** honors world laws, characters, visual DNA, and continuity.
- **Agency:** changes what a creator, player, or agent can do.
- **Evidence:** points to an artifact, commit, eval, release, or ledger entry.
- **Memory:** records meaningful state when appropriate.
- **Stewardship:** protects private memory, user work, and IP boundaries.
- **Product Sense:** moves toward a usable book, game, pack, course, or tool.

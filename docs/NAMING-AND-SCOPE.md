# Naming and Scope

## Decision

The whole system should not always be called Forge.

Forge is a strong metaphor for making artifacts, but this domain is broader:

- creator learning
- skill acquisition
- coding-agent capability
- swarm reputation
- game progression
- engine implementation
- research and standards
- evals and proof
- marketplace readiness

The right umbrella is **Mastery Engine**.

## Name Stack

| Name | Use for | Avoid using it for |
|---|---|---|
| Mastery Engine | The whole progression architecture | In-world lore flavor only |
| Epoch Forge | Arcanea crafting, artifacts, world products, relics | All skill learning or all agent progress |
| Academy | Lessons, learning paths, certifications, onboarding | Artifact crafting |
| Armory | Capability loadouts, agent builds, Unity ability sets, reusable tools | Moral rank or certification |
| Trials | Tests, evals, gates, challenges, boss checks | Passive XP accumulation |
| Codex | Research, references, knowledge unlocks, lore ledgers | Action execution |
| Swarm | Multi-agent crews, dispatch, reputation, role leveling | Single-player skill trees |
| Citadel | Durable product bundles, published worlds, games, courses | Small one-off artifacts |

## Product Language

External plain-language names:

- Mastery Paths
- Skill Trees
- Agent Loadouts
- Trials
- Proofs
- Creator Rank
- World Tier

Arcanea-flavored names:

- Luminor Path
- Epoch Forge
- Relic
- Gate Trial
- Citadel
- Swarm Rank
- World Memory

## Rule

Use plain names in platform UI and docs. Use Arcanea names when the user is inside a world, creator pack, lore product, or branded experience.

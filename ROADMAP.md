# Roadmap

## v0.1 Public Foundation

- Naming doctrine: Mastery Engine as umbrella, Forge as one Arcanea track.
- Research synthesis from major progression systems.
- Markdown-first Mastery Engine standard.
- Unity, Unreal, web, and agent runtime adapter notes.
- Starter skills for agent progression, coding-agent mapping, MD skill trees, and Unity progression.
- Validation script and GitHub Actions workflow.
- Arcanea Mastery Engine doctrine, progression system, swarm mastery, product ladder, ledger/proof spec, and example world mastery folder.

## v0.2 Research Depth

- Add deeper case studies for Warframe, EVE Online, RuneScape, FFXIV, Destiny, Fortnite, Path of Exile, Diablo, Hades, Factorio, Minecraft, Roblox, Duolingo, and GitHub contribution systems.
- Split research into `docs/research/<system>.md`.
- Add pattern taxonomy: mastery, loadout, trial, season, crafting, reputation, economy, social, collection, proof.

## v0.3 Schemas

- Add JSON Schemas for tracks, nodes, trials, rewards, agent cards, and ledgers.
- Add a graph validator for missing prerequisites, circular dependencies, unreachable nodes, and reward inflation.
- Add example generated index files.

## v0.4 Engine Generators

- Add Unity ScriptableObject generator.
- Add Unreal data asset / Gameplay Ability System mapping generator.
- Add web JSON export.
- Add AO/SO queue task generator.

## v0.5 Arcanea Integration

- Reframe the Arcanea Forge doc under Mastery Engine.
- Add Arcanea world-repo examples under `examples/arcanea-world-mastery/`.
- Add First Trial templates for world, agent, skill, and product mastery.
- Add `mastery-state.mjs` for Arcanea world repos.
- Add AO/SO queue templates for Mastery Engine work.
